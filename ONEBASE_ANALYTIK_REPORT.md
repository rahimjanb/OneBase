# OneBase Analytik — итоговый отчёт

Дата: 11.11.2026. Ветка `macbook-pro`, **ничего не закоммичено**. Документация модуля — `docs/analytik.md`, аудит перед разработкой —
`ONEBASE_ANALYTIK_AUDIT.md`.

## 1. Итог

Раздел «Аналитик» (OneBase Intelligence) построен и проверен на копии рабочей базы в настоящем интерфейсе (компьютер 1440 px и телефон
390 px), под пятью пользователями с разными правами. Аналитик только читает данные: запись в бизнес-таблицы невозможна ни из кода, ни на
уровне базы (отдельная роль только на чтение — проверена).

Что требует вашего решения — раздел 9: подключение роли только на чтение в `.env`, живая проверка чата на платной модели, коммит.

**«Проанализируй всю компанию»** (`analytik_dashboard`). Состояние 24 из 100, «критическое»: −36 критические риски (12), −20
предупреждения (8), −15 план продаж (прогноз 77,4 %), −5 одно просроченное производственное задание. Октябрь к сентябрю: выручка

## 8. Исправлено по ходу живой проверки

- Ложная тревога «Оплаты 10.11 ниже обычного на 100 %» — правило теперь ждёт загрузки оплат за вчера.
- «Нет данных» вместо 0 и вместо «−100 %» там, где источник ещё не был загружен (оплаты, закупки, Verifix); сравнение — только когда прошлый
  период покрыт данными (было «+2 434 %» по опозданиям).
- Свой период из целых месяцев сравнивается с целыми месяцами (октябрь — с сентябрём, а не с 31.08–30.09).
- Пользователь с частью прав видел «Состояние компании 100 — всё под контролем» при 12 критичных рисках компании — теперь «Состояние ваших
  разделов» с пояснением.
- РМ/супервайзер не видел ни одного риска — теперь видит находки по своим регионам.
- Уведомления: качество данных — только критичное, больше трёх находок — одно сводное (было 8 отдельных за проход).
- Чат Аналитика говорил «Консультант не настроен» и показывал Telegram консультанта; невидимая активная кнопка периода; бюджет «0 сум» без
  цен; значок «Прогноз» вылезал за карточку.

## 9. Что нужно от вас

1. **Роль только на чтение.** Запустить `deploy/analytik-readonly.sql` на рабочей базе с новым паролем и добавить
   `ConnectionStrings__AnalytikReadOnly` в `.env` API. Я `.env` не менял. Без этого Аналитик работает через основное подключение в
   транзакциях READ ONLY.
2. **Живой чат.** Ответы модели на демо-вопросы не запускались: `Ai__Safety__BlockPaidCalls=true`, а платные вызовы — только с вашего
   разрешения. Инструменты, на которых чат строит ответ, проверены (раздел 5).
3. **Ваша dev-база уже со схемой Аналитика.** Ваш API на :5081 перезапускался с этим кодом и применил миграцию `Analytik1_Core` (создаёт
   схему `analytik` и колонку `ai.Conversations.Kind` со значением по умолчанию — данные не меняются). Фон Аналитика один раз отработал в
   19:58 и отправил пользователю `test` 8 уведомлений (до ужесточения правил уведомлений).
4. **Коммит.** Изменения не закоммичены; в дереве есть и чужие изменения параллельной сессии.

## 10. Не сделано / ограничения

- Разбор документов (OCR, договоры, счета) отдельно не построен — используется существующая база знаний (Qdrant).
- Интерфейс на английском — в OneBase его нет (английский — в ответах чата).
- Чистая прибыль, расходы компании, мощности линий, связь продаж с техкартами — данных в OneBase нет; Аналитик так и отвечает.
- Платежи поставщикам — отложены до модуля «Финансы».
