Дата: 07.11.2026. Основа — `b72af60`. ТЗ — «departments-overview-implementation-prompt.md», макеты «Отделы — Laptop» и «Отделы — Mobile».

## Что сейчас

- **Страница** `app/(app)/departments/page.tsx` (серверная):
  - 6 карточек в порядке списка `departments` из `lib/demo-data.ts`;
  - карточка `DepartmentStatusCard`: название, процент, точка статуса, подпись, полоса;

  - месяц всегда текущий, выбора периода нет.

| Продажи | прогноз выполнения плана (у закрытого месяца — выполнение) | **факт** к плану | выполнен — «План выполнен», прогноз ≥ 100% — «В норме», ниже — «Требует внимания» | `/api/sales/overview` (есть год и месяц) |

  - Источника «Выпуск продукции» (выпуск к плану) нет: производственные задания есть, плана выпуска нет.

## Что даёт ТЗ и чего не хватает

| ТЗ | Есть | Нужно |
|---|---|---|
| Иконка отдела, метка статуса с иконкой, период у значения | точка статуса, иконки другие | Иконки по ТЗ (factory, wallet, shopping-cart, megaphone, package, users); метки «План выполнен», «В норме», «Требует внимания», «Нет данных» |
| Полоса цветом статуса; у продаж — двухслойная (факт + прогноз) с легендой | полоса продаж — только факт | Двухслойная полоса: факт ярко, прогноз бледно, легенда «Факт 62,3 из 437,4 т · 14%», «Прогноз 52%» |
| Строка деталей на подложке | подпись мелким текстом | Продажи — легенда; снабжение — «К закупке N · просрочено N»; HR — «Явка сегодня: N%» или «Сегодня отметок пока нет» |
| Выбор месяца, в адресе | нет | `?month=2026-11`: продажи — по месяцу, HR — явка за месяц; см. вопрос 2 о показателях «на сегодня» |
| Вид «сетка / список» | нет | Переключатель, выбор — в адресе |
| Подсказка с порогом у метки статуса | нет | «Цель ≥ 80%, сейчас 82%» и т. п. — по текущим порогам |
| Скелетоны, «Не удалось загрузить · Повторить» у одной карточки | без доступа и при ошибке — одинаково «нет данных» | Ошибка ≠ нет доступа: у ошибки — «Повторить» |
| Телефон: список карточек, период в шторке, pull-to-refresh | общая сетка в одну колонку | Компактные карточки по макету, период — шторкой, обновление жестом |

## Как сделаю, если не скажете иначе

- **Цвета и шрифт — токены приложения**, а не палитра из ТЗ: тёмная тема OneBase уже такая, как на макете. Замена общих токенов изменила бы
  все разделы.
- **Языки — русский и узбекский**, как во всём приложении: английского в OneBase нет, добавлять его ради одной страницы не стоит.
- **Статус «Критично»** — в текущих правилах его нет, не добавляю. Есть «Нет данных» — серая метка.
- **Расчёт показателей и порогов не меняю**; порядок отделов — как сейчас, без группировки по статусу.
- **Поиск на телефоне** — в шапке приложения уже есть кнопка поиска; второй такой кнопки рядом с «Отделы» не будет.

## Решения (07.11.2026)

1. **«Производство», «Финансы», «Маркетинг» — «Нет данных».**
   - Значение «—», пустая полоса, «Нет данных за {месяц}», серая метка.
   - Числа из `lib/demo-data.ts` на странице больше не показываются. Показатели появятся, когда будут источники.
2. **Прошлый месяц — только то, что есть за месяц:**
   - продажи — выполнение плана того месяца;
   - HR — явка за тот месяц, без строки «сегодня»;
   - снабжение — «Показатель только на сегодня», без числа.

## План этапов

Каждый этап — отчёт, сборка, тесты и проверка перед следующим.

1. **Данные и компьютер:**
   - карточки собираются чистыми функциями с тестами: статус, значение, период, полосы, детали, подсказка порога, ошибка;
   - месяц в адресе, загрузчики с месяцем;
   - новая сетка, вид «список», пояснение, скелетоны, «Повторить».
2. **Телефон:** компактные карточки, период — шторкой, pull-to-refresh; нижняя панель не меняется.
3. **Проверка:** настоящие данные (только чтение), русский и узбекский, обе темы, доступность (progressbar, подписи), снимки, итоговый
   отчёт.
