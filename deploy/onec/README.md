# Сертификат 1С для службы интеграции

Если публикация 1С (IIS/Apache на 192.168.9.141) использует сертификат внутреннего центра сертификации или самоподписанный,
положите сюда его файл (PEM или DER), например `onec-ca.crt`, и укажите в `.env`:

```
ONEC_CA_CERT_PATH=/etc/onebase/onec/onec-ca.crt
```

Папка подключается в контейнер `onec-worker` только для чтения. Проверка сертификата не отключается: цепочка строится до этого
корня, имя сервера проверяется. Закрытые ключи сюда не кладите — нужен только сертификат.
