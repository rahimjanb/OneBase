# ИИ-агент в Telegram: номер у агента, вакансии OneBase, «почему не отвечает» — план

Запрос: «ИИ-агент не отвечает в TG; пусть знает вакансии, которые добавили рекрутеры (данные вакансий из OneBase); у каждого ИИ-агента —
выбор аккаунта Telegram, через который он отвечает».

## Почему молчит (по коду, база production не смотрелась)

1. **Номер не работает на отдел агента.** Аккаунт без «Подразделений» целиком у продаж (`TelegramRoute.Legacy`): сообщение уходит агенту
   продаж, рекрутер его не получает. Выбрать номер в самом агенте нельзя — только в «Настройки → Telegram → Подразделения».
2. **Рекрутер знает только вакансии с «Миссией AI-рекрутера».** Нет ни одной такой открытой — кандидату без вакансии AI не отвечает
   (`RecruiterAgent`: `openAi.Count == 0 → return`); кандидату вакансии без галочки — тоже. В промпте у кандидата без вакансии — только
   код, название, город и зарплата, без описания, требований и условий.
3. Мелкие: агент выключен по умолчанию; рабочее время 9–19 пн–сб, вне его ответ ждёт утра; режим «С проверкой»; диалог «не распределён»
   (человек из списка агента продаж на общем номере).

## Этапы

1. **Номер у агента** (backend + экран): `ai.DialogAgents.AccountId` (новый столбец, `ON DELETE SET NULL`), `PUT /api/agents/{id}/account`.
   - Выбор номера (администратор Telegram/AI): номер начинает работать на отдел агента, новые диалоги — отделу агента; номер без
     подразделений сохраняет продажи (рассылки, автоотчёты, агент продаж своим людям). Диалоги «не распределён (нет отдела по умолчанию)»
     на номере — отделу агента. Аудит.
   - Остальные (HR, руководитель отдела) — только номера, которые уже работают на их отдел, настройки номера не меняются.
   - Номер уже у агента другого отдела — отказ.
   - Агент с номером отвечает только на этом номере; на номере — агент этого номера, иначе свой агент вакансии, иначе агент отдела без
     номера по умолчанию. Рекрутер, помощник отдела, напоминания — одно правило.
   - Маршрутизатор: человек из списка агента продаж на номере, который работает и на продажи, — продажам (а не «не распределён»): выбор
     номера у агента не отнимает у агента продаж его людей.
2. **Вакансии OneBase**: рекрутер видит все открытые вакансии — название, отдел, город, занятость, зарплата (если можно), описание,
   требования, условия; у кандидата с вакансией — она целиком и список остальных. Отвечает без галочки у вакансии; галочка у вакансии
   убрана из экрана (столбец остаётся, не удаляется). Проверка и напоминания — так же.
3. **«Почему агент может не отвечать»** на странице агента: включён ли, номер и его состояние, куда идут новые диалоги, рабочее время,
   режим, вакансии, пауза Telegram, очередь отправки, последние диалоги номера — куда ушли и почему, последние ошибки.

Каждый этап — сборка, тесты (подставные модель и Telegram), проверка в UI на отдельной базе, отчёт. Ни одного настоящего сообщения
Telegram и платного вызова; production, `.env`, сессии не трогаются.
