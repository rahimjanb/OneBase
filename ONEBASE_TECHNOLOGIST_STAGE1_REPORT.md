# OneBase — «Производство → Технолог»: этап 1 (сервер: техкарта и расчётный механизм) — отчёт

Дата: 08.11.2026. [Аудит и план](ONEBASE_TECHNOLOGIST_AUDIT.md).

## Что сделано

- **Технологическая карта на существующих рецептурах.** Новых справочников продуктов, материалов и единиц нет: версия рецептуры получила
  поля карты (номер, технолог, дата начала действия), параметры замеса и упаковки.
- **Этапы** — своя цепочка у каждого продукта, ничего не зашито в код: тип операции, участок, нормативный выход с допуском, база брака,
  влажность, переработка.
- **Компоненты по этапам** — на выход рецептуры, на замес, на штуку, упаковку или коробку; группы; единица строки с переводом в единицу
  склада; масса единицы. Одна позиция может быть на нескольких этапах.
- **Виды брака** — продукта (норматив этапа) и материала (к расходу материала, продукцию не трогает).
- **Утверждение версий:** черновик → на утверждении → утверждена → архив.
  - Утверждает другой технолог или начальник производства, свою версию не утвердить.
  - Вернуть — с причиной; автор может отозвать.
  - На утверждении и после утверждения версия не правится.
- **Сравнение двух версий** — что добавлено, убрано, изменено.
- **Production Calculation Engine** (`ProductionCalc`):
  - **плановый расчёт** — по нормативам выхода и брака каждого этапа;
  - **расчёт по результатам** — фактический выход, брак по этапам, замесы, упаковки, брак материалов, возврат переработки;
  - детализация по этапам (обработано, годное, брак, массы), замесам и компонентам: чистый расход, нормативные потери, норма, с
    фактическим браком;
  - нет данных этапа — расчёт помечен неполным, нули не подставляются;
  - ошибки карты показываются вместо отрицательных количеств и деления на ноль.
- **Задания** — потребность по расчёту утверждённой версии, снимок расчёта хранится в задании; норма на фактический выход — тем же расчётом.
  Новая версия не меняет посчитанные задания.

## API

- **Новое:**
  - `POST /api/production/recipes/{id}/submit`, `…/approve`, `…/return`;
  - `GET /api/production/recipes/{id}/compare/{other}`.
- **Изменено:**
