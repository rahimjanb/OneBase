# OneBase — накопительная акция Twizos в автоотчётах Telegram: итоговый отчёт (этап 4 и всё целиком)

Дата: 05.11.2026. Аудит и решения — [ONEBASE_TWIZOS_PROMO_AUDIT.md](ONEBASE_TWIZOS_PROMO_AUDIT.md); этапы —
[1](ONEBASE_TWIZOS_PROMO_STAGE1_REPORT.md), [2](ONEBASE_TWIZOS_PROMO_STAGE2_REPORT.md), [3](ONEBASE_TWIZOS_PROMO_STAGE3_REPORT.md);
документация — [docs/incentive.md](docs/incentive.md).

Акция Twizos встроена в существующую автоматическую отчётность как **9-й автоотчёт «Накопительная акция»**. Отдельной системы рассылки нет: нет
второго бота, нет второго клиента Linko, нет новых фоновых служб. «Поле боя» и остальные отчёты работают как раньше. Акция в базе
**выключена**, запуски выключены. Включает администратор во вкладке «Акции» и в «Расписании».

## Как работает расписание

Шесть запусков, время по Ташкенту, по умолчанию выключены:

| Запуск | Когда |
|---|---|
| Маршрут дня | 08:30 пн–сб |
| Полдень | 13:00 пн–сб |
| Итог дня | 18:00 пн–сб, после «Поля боя» |
| Итог недели | суббота 18:00 |
| Рейтинг | суббота 18:30 |
| Итог месяца | 18:00 в последний рабочий день месяца (30.11 и 31.12; если месяц кончается воскресеньем — в субботу) |

Правила:
- Включение или смена времени действует с этого момента; уже прошедшее время не догоняется.
- Если сервер не работал, запуск догоняется в пределах «догона», иначе — «пропущен».
- Запуски в одно время ставятся в очередь по каталогу, поэтому «Поле боя» уходит раньше акции.
- Вне периода акции или при выключенной акции — «пропущено» с причиной.

## Как определяется получатель

| Получатель | Что получает |
|---|---|
| ТП | Получатель с ролью «ТП» и его чат: только своя карточка, область проверяется при каждом построении. Рейтинг ТП лично не получает |
| СВ | Регион и супервайзер: сводка команды региона; в 08:30 и 18:00 — копии карточек ТП региона, подписанных на акцию (если никто не подписан — все ТП региона, до 10). Рейтинг — по региону |
| РМ | Направление (или «вся страна»): сводка регионов, по настройке — ещё и карточки ТП. Рейтинг — по направлению |
| Канал | Получатель «РМ · вся страна» с групповым чатом и запуском «рейтинг акции» |

Telegram ID — чаты из диалогов аккаунта: личный чат человека (может быть подтверждён кодом) или группа. Чат недоступен — пропуск с причиной.

## Оставшиеся вопросы и ограничения

1. **Включение.** Акция и запуски выключены. Перед стартом:
   - проверить пороги — ТЗ, раздел 3: при текущем темпе до планшета не доходит никто;
   - проверить список оптовых и узбекские тексты (их лучше прочитать носителю языка);
   - включать постепенно — аккаунт личный, Telegram ограничивает массовые сообщения (`PEER_FLOOD`).
2. **«Поле боя»:** на значке «отказ» нет креста — в шрифте нет символа «✕». В карточках акции это исправлено. В «Поле боя» не трогал — нужно ваше решение, исправление изменит его картинки.
3. **ТП без плана визитов в Linko** получает маршрут «по истории», и он может не совпасть с реальными визитами. Решение — вести план визитов в Linko.
4. **Цель маршрута по правилу ТЗ** (набор на каждый магазин) может быть сильно больше нормы дня. При необходимости можно ограничить число магазинов с целью.
5. **Картинки призов** есть для планшета, телевизора и телефона. Для других призов будущих акций — без картинки, пока не добавить PNG в сборку.
6. **«Накоплено» утром может быть меньше вчерашнего вечернего** — вчерашние заказы ещё не доставлены. Так по ТЗ, решение 05.11.2026.
7. **Коммит.** В общих файлах (`OneBaseDbContext`, `IAppDbContext`, `DependencyInjection`, снимок модели, Designer миграции) лежит и незакоммиченная работа «Цифрового двойника» другой сессии. При коммите её нужно исключить, как раньше.
