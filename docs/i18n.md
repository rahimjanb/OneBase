# Языки интерфейса: русский и узбекский (латиница)

Кнопка языка (RU / UZ) — в шапке рядом с уведомлениями (OneBase и Sales Base) и на странице входа. Выбор хранится в cookie
`onebase_lang` на год; по умолчанию — русский. Смена языка перезагружает страницу: сервер и браузер сразу рисуют её на новом языке.
Язык уходит и на сервер (заголовок `Accept-Language` — из `/bff`, `lib/server-api.ts`, `lib/field/api.ts`).

## Как устроено

- Ключ перевода — сам русский текст: `t("Задачи")` → «Vazifalar». Перевода нет — остаётся русский: ничего не ломается, непереведённое видно.
- Подстановки — `{имя}`: `t("Осталось {n} дн.", { n: 3 })`. В словаре — с той же подстановкой: `"Осталось {n} дн.": "{n} kun qoldi"`.
- Словари узбекского — `frontend/src/i18n/uz/*.ts`, по разделам (`common`, `home`, `tasks`, `files`, `ai`, `dataManager`, `campaigns`,
  `settings`, `sales`, `salesPages`, `field`, `lib`), собираются в `uz/index.ts`. База — `fieldControl.ts`: 747 терминов из узбекского
  словаря «Полевого контроля» (те же слова, что уже видят сотрудники); словари разделов перекрывают её.
- Код: `frontend/src/i18n/core.ts` (языки, `translate`), `server.ts` (`getT`, `getLang`, `getLocale`), `client.tsx` (`useT`, `useLang`,
  `useLocale`, `Tr`, `setLang`).

## Сервер и AI

- Язык запроса на сервере — `UiLanguage` (`OneBase.Application.Abstractions`): ставит middleware API по `Accept-Language`, фоновая
  работа из запроса (ответ консультанта дописывается после закрытия вкладки) наследует его. Вне запроса — русский.
- AI-консультант, AI-сотрудники и AI Data Manager отвечают на языке вопроса, а по умолчанию — на языке интерфейса
  (`UiLanguage.DefaultAnswerLanguage` в правилах качества и инструкции Data Manager). Telegram-агент — по своей настройке языка.

## Тексты сервера

Сервер присылает тексты по-русски (пояснения, подписи, статусы, ошибки) и не переводит их: его кэши готовых страниц общие для всех
пользователей. Перевод — на фронтенде тем же словарём: `t()` узнаёт готовый текст по ключу-шаблону — `"данные по {date}"` переводит
«данные по 19.10» в «19.10 holatiga ma'lumot» (у шаблона должен быть постоянный кусок от 4 символов; пойманное значение, которое само
есть в словаре, тоже переводится). Ключи текстов сервера — в `uz/server*.ts`; места показа обёрнуты `t(...)`. Ошибки API переводятся
в одном месте — `lib/bff.ts`. Если сервер поменяет формулировку, текст останется русским, пока не обновить ключ.

Даты — `formatDate` из `i18n/core.ts`: узбекские названия месяцев и дней собираются в коде, потому что в Chrome их нет в Intl
(«M10 18»), а на сервере (Node) есть — иначе сервер и браузер рисовали бы разное.

## Как переводить код

1. Клиентский компонент (`"use client"`): `const t = useT();` (из `@/i18n/client`) в каждом компоненте, который рисует текст;
   текст — `{t("…")}`, атрибуты — `aria-label={t("…")}`, `placeholder={t("…")}`, `title={t("…")}`.
2. Серверный компонент (страница `page.tsx`, `layout.tsx` и компоненты, которые подключаются только с сервера, могут быть `async`):
   `const t = await getT();` (из `@/i18n/server`).
3. Общий компонент без `"use client"`, который подключают и клиентские компоненты (его нельзя сделать `async`): текст — `<Tr>Назад</Tr>`,
   с подстановкой — `<Tr vars={{ n }}>{"Осталось {n} дн."}</Tr>` (из `@/i18n/client`); атрибуты — принять готовую строку пропсом
   или вынести кусок в маленький клиентский компонент.
4. Подписи в константах модуля (меню, статусы, колонки таблиц) остаются русскими — переводятся там, где рисуются: `t(item.label)`.
   Сравнения и логика (`status === "…"`, разбор текста сервера, регулярные выражения) — не трогать.
5. Шаблонные строки: `` `Уведомления: ${n} новых` `` → `t("Уведомления: {n} новых", { n })`. Склонения по числу (`plural(n, "задача",
   "задачи", "задач")`) — каждое слово через `t`: в узбекском форма одна (`vazifa`).
6. `export const metadata = { title: "Задачи · OneBase" }` → `export async function generateMetadata() { const t = await getT();
   return { title: t("Задачи · OneBase") }; }`.
7. Даты с названиями месяцев и дней — `formatDate(date, locale, options)` из `@/i18n/core` с локалью `useLocale()` / `await getLocale()`;
   не `toLocaleDateString(locale)` и не `Intl.DateTimeFormat(locale)` — в Chrome узбекских данных Intl нет.
   Числа можно оставить `ru-RU` (разделители те же).
8. Не переводить: данные (имена, точки, товары, регионы, дилеры из Linko), бренды (OneBase, Sales Base, Linko, Telegram, Google),
   комментарии, журналы в консоль, пути и ключи API.
9. Каждую новую русскую строку — в словарь своего раздела с узбекским переводом. Ключ — точно тот же текст, что в `t(...)`.

## Как писать по-узбекски

Латиница, обычный апостроф: `o'`, `g'`, `ma'lumot` (как в «Полевом контроле»). Обращение — на «siz». Кнопки — действие:
«Saqlash», «Bekor qilish». Коротко, без канцелярита. Сокращения отдела продаж — как в эталоне: ТП → TP, АКБ → AKB, РОП → ROP, СВР → SVR.
