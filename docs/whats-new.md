# Окно «Что нового»

После обновления 1Base пользователь при входе видит окно «Что нового»: пошаговый рассказ о новых разделах. В окне есть кнопки «Назад»,
«Далее» и «Закрыть». Макет — `untitled.pen`: фреймы `fIyJU` и `OkLhT` для компьютера, `nOeLF` и `IeSiY` для телефона.

## Кому и когда

- **Только открытые разделы.** Каждый видит карточки только тех разделов, которые ему открыты, по тем же правам, что и меню. Нумерация шагов
  при этом пересчитывается. Если открытых карточек нет, окна нет.
- **Один раз на версию.** Окно закрыто любым способом: крестик, «Закрыть», «Готово», Esc, клик по фону, свайп вниз или переход по «Где
  найти». После этого окно этой версии больше не появляется — ни после перезагрузки, ни на другом устройстве.
- **Новым пользователям само не показывается.** Если пользователь создан в день релиза или позже (по Ташкенту), окно само не появляется: для
  него и так всё новое.
- **Не перебивает работу.** Окно появляется через 0,7 с после загрузки, когда погасла заставка. Если открыто другое окно или шторка, оно
  ждёт следующего перехода между страницами.
- **Снова — вручную.** Профиль → «Что нового»: меню аватара на компьютере, «Профиль» на телефоне. Повторное закрытие ничего не меняет.

**Где хранится отметка.** Отметка «просмотрено» хранится в профиле, в колонке `Users.WhatsNewSeen` (последняя закрытая версия). Её
дублирует запись в браузере `onebase.whatsNew.seen.<id пользователя>`: если запрос на сервер не дошёл, окно не повторяется, а отметка
досылается при следующем входе.

API:
- `/api/auth/me` отдаёт `whatsNewSeen` и `createdAt`;
- `POST /api/auth/whats-new { version }` записывает отметку. Более ранняя версия отметку не откатывает.

## Экраны

| Экран | Вид |
|---|---|
| Компьютер (от 1024 px) | Окно 1000 px. Слева — список шагов: пройденный с галочкой, по шагу можно кликнуть. Справа — превью, текст, «Где найти», «Назад», «Далее» / «Готово, начать работу». Клавиши: → — следующий шаг, ← — назад, Enter — «Далее» / «Готово», Esc — закрыть |
| Планшет (768–1023 px) | То же без списка шагов, ширина до 720 px |
| Телефон | Шторка снизу. Свайп влево / вправо — шаги, вниз по шапке — закрыть. Кнопки высотой 50 px, под ними «Закрыть» и подпись «Окно больше не появится после закрытия» |

- **Высота окна** на компьютере и планшете постоянная, чтобы окно не прыгало между шагами. Длинный шаг прокручивается внутри.
- **Превью** — схема раздела без имён и чисел: в 1Base нет выдуманных данных.

## Новый релиз

1. В `frontend/src/lib/whats-new.ts` в `CURRENT_RELEASE` поменять `version` и `date` на дату релиза.
   Второе обновление за день — `2026-11-13.2`.
2. Заполнить шаги (3–7), у каждого шага:
   - заголовок, описание и короткое описание для телефона;
   - 2–4 пункта;
   - путь «Где найти» и `route`;
   - кому видна карточка (`need`): раздел меню, права или «ИИ-агенты».
3. Схема превью — в `components/whats-new/WhatsNewPreview.tsx`, по `icon` шага.
4. Перевод — в `frontend/src/i18n/uz/whatsNew.ts`. Кириллица строится из латиницы сама.
5. Проверка: `node --test src/lib/whats-new.test.mjs`.

После выхода новой версии окно один раз появится у всех, у кого есть хотя бы одна открытая карточка.
