## 3. Производительность и офлайн

- Кэш репозитория (память + SQLite): текущие данные живут минуту, закрытые месяцы — неделю, прошлые недели — сутки; одинаковые
  запросы в полёте объединяются. Блоки экрана показывают последнее успешное состояние с временем синхронизации.
- Тяжёлый ответ `/api/sales/republic` (≈ 230 КБ) разбирается в фоновом изоляте, в кэш попадает только срез для экрана.
- Очередь отправки (outbox): только идемпотентные операции (прочитано, настройки уведомлений); уходит при появлении сети и при
  возврате в приложение; отказ сервера не повторяется. Складские и производственные операции — только при ответе сервера, без
  «оптимистичного» вида (у каждой — ключ идемпотентности).
- Кэш чистится от записей старше 30 дней при запуске; выход и смена пользователя очищают очередь.

## 4. Безопасность

- Токен — в Keychain / Keystore (`flutter_secure_storage`); после переустановки старый вход из Keychain не подхватывается.
- На 401 сеанс закрывается; при возврате в приложение перечитывается профиль (права действуют без повторного входа).
- Журнал запросов — только в debug-сборке (`kDebugMode`); в release тела и заголовки не пишутся.
- Сеть: Android release не пускает HTTP (targetSdk ≥ 28, без `usesCleartextTraffic`); iOS ATS разрешает HTTP только в локальной сети
  (`NSAllowsLocalNetworking`) — боевой адрес должен быть HTTPS.
- Android: `allowBackup=false`, `fullBackupContent=false`, правила извлечения данных — кэш и токен не уходят в резервные копии.
- Платные вызовы AI — только по нажатию пользователя: без автоповтора, без очереди, `?ask=` не отправляет; голос (платный) не сделан.
- Имена людей из событий на телефоне не сохраняются; ответы консультанта не кэшируются.

## 5. Что нужно от владельца до публикации

1. **Боевой адрес API** (HTTPS) — `mobile/env/production.json` → `API_BASE_URL`. Сейчас пусто: release-сборка запускается и
   показывает «адрес сервера не задан».
2. **Подпись Android**: keystore загрузки и `key.properties` (сейчас release подписывается debug-ключом шаблона Flutter — для
   публикации в Google Play не годится). Принять лицензии Android SDK на этой машине (`flutter doctor --android-licenses`).
3. **Apple**: команда Apple Developer, bundle id, профили — для подписанной сборки и TestFlight. При отправке проверить, требует ли
   App Store описания доступа к фото у `file_picker` (приложение использует только выбор файлов).
4. **Push FCM/APNs (P1)**: проект Firebase и ключ APNs; на сервере — таблица устройств (миграция), `POST/DELETE /api/push/devices`,
   отправка через FCM рядом с Web Push. Без этого уведомления приходят только при открытом приложении (опрос счётчика раз в минуту).
5. **Предложения бэкенду** (не реализованы, API нет): смена своего пароля (`POST /api/auth/password`), список и закрытие своих сеансов
   (`GET/DELETE /api/auth/sessions`); P2/P3 — компактные ряды продаж и недельные тренды на сервере (меньше трафика на главной).

## 6. Что не проверено вживую

- Вопрос консультанту (поток ответа) — платный вызов модели; проверен только на фейковом сервере, на симуляторе открыт сохранённый чат.
- Записи на dev-стенде (создание задачи, складские операции, отметки «прочитано», правка клиента, «Проверить сейчас» у находок) —
  только на фейковом сервере в тестах; на симуляторе формы только открывались.
- Android на эмуляторе / устройстве не запускался (собран, см. п. 1). Физический iPhone не использовался.
- Push (нет FCM). Узбекский перевод текстов находок AI шаблонами (как `alertText` веба) — тексты находок показываются как с сервера.

## 7. Сборки

Команды (из `mobile/`, окружение `env/production.json`, 20.11.2026, Flutter 3.47.7, Xcode 27.2, Android SDK 36):

```
flutter build apk --release --dart-define-from-file=env/production.json        # ✓ Built build/app/outputs/flutter-apk/app-release.apk (74.3MB)
flutter build appbundle --release --dart-define-from-file=env/production.json  # ✓ Built build/app/outputs/bundle/release/app-release.aab (70.9MB)
flutter build ios --release --no-codesign --dart-define-from-file=env/production.json   # ✓ Built build/ios/iphoneos/Runner.app (28.3MB)
```

- Подпись APK проверена `apksigner verify --print-certs`: `CN=Android Debug` — ключ шаблона Flutter, для Google Play нужен свой.
- Лицензии Android SDK на этой машине приняты не все (`flutter doctor`), сборкам это не помешало.
- В `production.json` адрес API пуст — собранные release-приложения откроют экран «Адрес сервера не задан при сборке приложения.»
  Пересборка после получения адреса — те же команды.
- Размер APK можно уменьшить в 2–3 раза: `flutter build apk --release --split-per-abi` (отдельный файл на архитектуру); в Google Play
  AAB и так раздаётся по архитектурам.
