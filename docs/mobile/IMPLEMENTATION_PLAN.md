# OneBase Mobile — план реализации

Порядок этапов — из мастер-промпта. После каждого этапа:
1. `flutter analyze` — без замечаний.
2. Тесты этапа.
3. Проверка в симуляторе на настоящем API.
4. Отчёт в [PROGRESS.md](PROGRESS.md).
5. Коммит только файлов этапа (в общем рабочем дереве работают и другие сессии — `git add` по путям, никогда `-A`).

Проверка на настоящих данных идёт на локальном dev API (:5081): вход тестовым администратором, только чтение. Кнопки, которые
пишут данные или вызывают платный AI, на dev-стенде не нажимаются. Записывающие сценарии проверяются на отдельной временной базе
и отдельном экземпляре API.

## Что нужно от владельца (по мере этапов)

| Когда | Что |
|---|---|
| Этап 11 | Проект Firebase (`google-services.json`, `GoogleService-Info.plist`), ключ службы FCM для сервера; APNs-ключ Apple |
| Этап 13 | Боевой домен API; подпись Android (keystore) и Apple Developer для публикации; принятие лицензий Android SDK на этой машине |
| По желанию | Решение по расширениям P2/P3 (компактные ряды продаж и недельные тренды на сервере) |
