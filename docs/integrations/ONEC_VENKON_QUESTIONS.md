# Вопросы к VENKON GROUP по интеграции 1С → OneBase

К спецификации [ONEC_API_SPECIFICATION.md](ONEC_API_SPECIFICATION.md). Ответы нужны, чтобы подключить OneBase к рабочей
1С:Бухгалтерии для Узбекистана. Пароли и ключи — не в ответе на этот документ, а отдельно администратору OneBase.

## 1. Сервер и сеть

1. Какой веб-сервер будет публиковать 1С (IIS или Apache) и кто его установит и настроит?
2. Точный адрес публикации: `https://192.168.9.141/<имя публикации>/hs/onebase/v1` — какое имя публикации и порт (443?)?
3. Сейчас с сервера OneBase (192.168.9.168) нет ответа на ping и TCP 443 на 192.168.9.141 (timeout). Что закрывает
   доступ: брандмауэр Windows, правило на ESXi/виртуальном коммутаторе, отсутствие веб-сервера? Кто откроет доступ
   **только** с адреса 192.168.9.168 на порт публикации?
4. Какой сертификат будет у публикации: внутренний центр сертификации или самоподписанный? Пришлите файл сертификата
   (`.crt`, PEM) — OneBase будет доверять ему явно, без отключения проверки.
5. Есть ли окна недоступности (обновление конфигурации, закрытие месяца, резервное копирование) — в какие часы?

## 2. Конфигурация 1С

6. Точное название и версия конфигурации («Бухгалтерия для Узбекистана», редакция, релиз), версия платформы 1С.
7. Сколько организаций ведётся в базе и какие из них нужны OneBase?
8. Есть ли в базе доработки VENKON (свои документы, регистры, реквизиты), которые влияют на проводки?
9. Как называются в конфигурации документы для каждого типа из спецификации (реализация, возврат, поступление,
   касса, банк, производство, требование-накладная, перемещение, списание, ручная операция)?
10. Виды субконто: пришлите полный список видов субконто плана счетов (или выгрузку плана счетов с субконто).
11. Ведётся ли учёт по подразделениям (субконто или отдельное измерение регистра)?
12. Ведётся ли партионный учёт и по каким счетам?
13. Где в базе срок оплаты: в договоре (отсрочка в днях), в документе реализации или нигде?
14. Откуда в базе курсы валют (загрузка с сайта ЦБ РУз, вручную) и бывают ли курсы «по договору»?
15. С какой даты в базе есть данные (начальные остатки — каким документом введены)?

## 3. API

16. Подходит ли предложенный формат (JSON, `GET`, страницы с курсором, проводки наборами по документу)? Что нужно
    изменить?
17. Можно ли сделать **план обмена** для регистрации изменений (метод `/changes`)? Если нет — хранится ли где-то момент
    изменения объектов и журнал удалений?
18. Можно ли отдавать `totals` (количество и сумму за отбор) для сверки полноты загрузки?
19. Какие ограничения нагрузки нужны со стороны 1С (одновременные запросы, запросов в секунду, размер страницы)?
20. Как будет обозначаться версия API и как VENKON будет сообщать об изменениях формата?
21. Какой вариант авторизации удобнее: Basic отдельного пользователя или токен? Кто создаст пользователя
    `OneBase_ReadOnly` и с какими правами (только чтение, без интерактивного входа)?
22. Сроки: когда может быть готова первая версия на тестовой копии базы и когда — на рабочей?
23. Есть ли тестовая копия базы, на которой OneBase может проверить загрузку до подключения рабочей?

## 4. Данные и ограничения

24. Какие данные нельзя передавать в OneBase (персональные данные сотрудников, зарплата по сотрудникам, ПИНФЛ)?
    Предлагаем не отдавать субконто «Сотрудники/Физлица» в проводках по зарплате.
25. Нужны ли OneBase данные налогового учёта (если он ведётся отдельно) или достаточно бухгалтерского?
26. Как в базе отражаются возвраты и корректировки прошлых периодов (исправительные документы или перепроведение
    старых)?
27. Бывают ли перепроведения закрытых месяцев? Как часто?
