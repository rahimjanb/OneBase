# OneBase — «Отделы» по ТЗ: этап 1 (данные и компьютер)

Дата: 07.11.2026. План и решения — в [аудите](ONEBASE_DEPARTMENTS_REDESIGN_AUDIT.md).

## Что сделано

1. **Карточки собираются чистыми функциями** (`lib/departments-view.ts`). Расчёт и пороги — прежние:
   - **Продажи:**
     - крупно — прогноз выполнения плана (у закрытого месяца — выполнение);
     - **полоса двухслойная** — ярко факт, бледно прогноз;
     - легенда «Факт 62,3 из 437,4 т · 14%» и «Прогноз 52%». Расхождения «52% крупно, 14% на полосе» больше нет.
   - **HR:**
     - крупно и на полосе — явка за месяц, норма 80%;
     - строка «Явка сегодня: N%», а пока отметок нет — «Сегодня отметок пока нет» вместо «0%»;
     - за прошлый месяц — без строки «сегодня».
   - **Снабжение:**
     - доля заявок к закупке без просрочки, строка «К закупке N · просрочено N»;
     - за прошлый месяц — «Показатель только на сегодня — за прошлые месяцы его нет».
   - **Производство, Финансы, Маркетинг** — «—», пустая полоса, «Нет данных за ноябрь 2026», серая метка. Числа из `lib/demo-data.ts`
     на странице больше не показываются.
2. **Выбор месяца** «📅 Ноябрь 2026 ▾» за последние 12 месяцев, в адресе (`?month=2026-10`).
   - Продажи — за этот месяц, HR — явка за его дни.
   - Неверный или будущий месяц в адресе — текущий.
3. **Вид «сетка / список»** — в адресе (`?view=list`).
   - Список: иконка · отдел с деталью · показатель с периодом · значение · полоса 200 пикселей · статус · стрелка.
   - На узком экране список показывается карточками.
4. **Карточка по макету:**
   - иконки отделов из ТЗ (factory, wallet, shopping-cart, megaphone, package, users; неизвестный — building-2);
   - метка статуса с иконкой: «План выполнен», «В норме», «Требует внимания», «Нет данных», «Не удалось загрузить»;
   - у «Требует внимания» — рамка и плитка цветом предупреждения;
   - значение 36 с периодом рядом, название показателя;
   - полоса цветом статуса, строка деталей на подложке;
   - карточка целиком — ссылка в отдел; при наведении приподнимается, есть фокус с клавиатуры.
5. **Подсказка у метки** — порог отдела: «Цель — прогноз от 100% плана, сейчас 52%», «Норма ≥ 80%, сейчас 82%», «Цель — без
   просроченных заявок, просрочено 0».
6. **Сетка:** три колонки, при ширине меньше 1200 — две, на телефоне — одна; карточки в ряду одной высоты. Под сеткой — пояснение, как
   считается статус.
7. **Состояния:**
   - скелетоны шести карточек, пока страница грузится (`departments/loading.tsx`);
   - нет доступа — «Нет данных» без числа;
   - сбой ответа одного отдела — «Не удалось загрузить показатели отдела» и «Повторить», остальные карточки работают. Для этого
     добавлен `apiOutcome`: он отличает 401/403 (нет доступа) от сбоя.
8. **Доступность:**
   - полоса — `role="progressbar"` с подписью («Продажи: факт 14%, прогноз 52%»);
   - карточка — подпись «Продажи, Прогноз выполнения плана 52%, Требует внимания»;
   - статус всегда текстом.
9. **Узбекский** — 24 новых перевода.

Порядок отделов прежний, без группировки по статусу. Сервер и база не менялись: нужные данные API уже отдают.

## Проверка

- Типы без ошибок, боевая сборка проходит.
- **Тесты фронтенда — 98/98**, из них 8 новых (`departments-view.test.mjs`):
  - порядок отделов;
  - месяц из адреса и последний день месяца, в том числе 29 февраля;
  - продажи как на макете: 52% крупно, полоса 14% и 52%, легенда, подписи для диктора;
  - статусы продаж по прежним правилам, закрытый месяц, «плана нет»;
  - нет доступа и сбой;
  - HR: «Сегодня отметок пока нет», прошлый месяц, только «сегодня»;
  - снабжение: на сегодня, прошлый месяц, заявки видят снабжение и директор;
  - «Нет данных» у трёх отделов.
- **Стенд**, карточки собраны теми же функциями из данных как на макете:
  - ширина 1440 (три колонки) и 1100 (две);
  - подсказка порога при наведении;
  - вид «список»;
  - светлая тема с карточкой «Не удалось загрузить».
- **Найдено и исправлено по снимкам:**
  - сетка была в две колонки вместо трёх — Tailwind ставил порог в пикселях перед `md` в rem, теперь `min-[75rem]`;
  - подложка строки деталей была не видна в тёмной теме: цвет страницы там прозрачный. Теперь подложка темнее карточки, а в светлой
    теме — цвета страницы.
- Настоящую страницу я не открывал (нужен вход) — это этап проверки.
